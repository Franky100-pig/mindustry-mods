# Mindustry 单机自动玩 — 入门 Logic 脚本

一个最小可用的自动化示例：**自动挖矿 + 自动反击**。不用写外部程序、不用编译、不会被判定为外挂。

## 这段脚本做了什么
- 用 `ubind` 接管你的飞行单位（默认 Poly）。
- 用 `uradar` 每帧扫描半径 60 内的敌人。
- 有敌人 → `ucontrol target` 锁定开火。
- 没敌人 → `ulocate ore` 找核心附近的铜矿，`ucontrol mine` 派去挖。

就这么 ~25 行，核心逻辑不到 10 行。

## 游戏内怎么搭（3 步）
1. **造单位**：放一个单位工厂（如 Air Factory），选 Poly，通电产至少 1 只。
2. **造处理器**：放一个 Processor（逻辑处理器），通电。
3. **贴代码**：点开 Processor → 点代码区 → 把 `auto-miner-defense.mlog` 的内容全选粘贴 → 点右上角运行（▶）。

> 提示：Processor 和工厂都要**通电**才会动。单位闲着（没被你手动操控）时才会被逻辑接管。

## 难度评估（回答"好不好做"）
- **自动挖矿 / 自动反击 / 自动修墙**：简单，本脚本就是模板，照着加 `ucontrol` 指令即可。
- **自动铺产线 / 自动建防御**：中等，需要 `ucontrol build` + 读核心库存（`sensor` 核心 `@copper` 等）做条件判断。
- **全自动推图 AI**：难，等于自己写一套策略，逻辑块能做的上限很高但不是"几行搞定"。

结论：**单机自动化上手很轻松**，先把这段跑通感受一下，再决定要不要往下加料。

## 下一步可以加的
- `sensor @copper coreAmount` 读核心铜库存，低于阈值才去挖；
- `ucontrol build x y @copper-wall 0 0` 让单位顺手补墙；
- 多只单位分工（一只专职挖、一只专职打）。
