# Mindustry Mods & Automation

Franky（`Franky100-pig`）的 Mindustry 实验仓库，收集我自己写的 **mod** 和 **自动化脚本**。

> 单机向。所有内容纯本地可用，不涉及任何联机作弊。

## 子项目

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| [`mindustry-first-mod/`](mindustry-first-mod) | 一个最小可运行 mod：自定义墙 Hyper Wall | 无需编译，丢进 mods 目录启用即可 |
| [`mindustry-automation/`](mindustry-automation) | 一段 Logic 脚本：自动挖矿 + 自动反击 | 粘进 Processor 即可让无人机自动干活 |
